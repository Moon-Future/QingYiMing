# 情义明系统操作手册

> 面向第一次使用情义明的同事。本文根据项目当前页面和业务代码整理，说明日常操作入口、字段含义、操作顺序和常见问题。Dify 知识库可直接导入本文件。界面版本更新后，实际按钮名称或布局可能略有变化。

## 1. 情义明系统是什么

情义明是公司内部使用的木业业务管理系统。当前版本包含基础资料、客户供货关系、订单、送货单、库存和二维码标签等功能。网页顶部显示登录用户，左侧是功能菜单，右侧是当前业务页面。

常用业务流程如下：

1. 维护公司、产品和计量单位等基础资料。
2. 建立客户与产品之间的供货关系。
3. 对按订单送货的客户，先登记订单；非订单送货的客户可根据供货关系直接开送货单。
4. 在“打印送货单”页面选择客户和产品，填写数量等信息，打印并保存。
5. 保存送货单后，系统记录送货明细；与订单关联的送货会更新订单已送量，送货也会生成出库记录并扣减库存。

操作正式业务数据前，请核对客户、产品、型号、数量、单位、日期和地址。保存或删除后可能影响订单及库存数据。

## 2. 登录、账号和权限

### 登录

打开情义明网页，在登录页输入账号和密码，然后选择“登陆”。登录成功后进入业务首页。完成操作后，点击页面右上角“退出”。

### 账号角色

- **管理员**：项目以 `root = 1` 标记。通常可维护基础资料、客户供货关系、订单、库存和二维码资料。
- **普通用户**：项目以 `root = 0` 标记。菜单主要开放打印送货单和历史送货单等日常送货功能。

若看不到某个菜单或按钮，通常是当前账号权限不包含该操作。请联系系统管理员，不要借用他人账号。

### 注册注意事项

注册页面需要姓名、账号、密码和注册码。系统依据注册码决定账号角色；注册码由系统管理员提供，不应写入公开文档或 Dify 知识库。注册后仍需使用自己的账号登录。

## 3. 页面通用操作

### 列表页

- 页面表格显示当前资料或业务记录。
- 表格下方分页按钮用于切换页面。
- 如果页面有搜索区，输入筛选条件后点搜索；清空筛选条件后重新搜索可恢复列表。
- “新增”进入新增表单；填写后点“提交”保存。带星号（`*`）的字段为必填项。
- 管理员可通过“编辑”修改记录。修改后在弹窗中点“更新”保存，点“取消”放弃本次修改。
- 删除前系统会弹出确认框。确认前先检查记录及关联业务；删除通常是软删除，即标记停用，不代表数据库物理擦除。

### 操作失败时

先查看页面弹出的错误提示，再确认网络、登录状态、必填字段、重复资料和关联资料是否存在。不要连续重复点击“提交”；先刷新列表核实刚才的操作是否已经成功。

## 4. 基础信息

管理员在左侧菜单“基础信息”下维护产品、公司、单位和二维码产品。

### 4.1 产品

路径：**基础信息 → 产品**。

产品资料包含产品名称、型号和计量单位。新增产品时：

1. 点击“新增”。
2. 输入产品名称和型号。
3. 从单位下拉列表选择计量单位。
4. 点击“提交”，检查成功提示并在列表中确认记录。

页面支持按型号搜索。系统会检查重复型号；如提示型号已存在，先搜索确认是否已维护，不要为了绕过重复校验随意更改型号。

产品型号会用于订单、供货关系、库存、送货单和出库记录。修改型号前，先确认对历史单据和用户识别是否有影响。

### 4.2 公司

路径：**基础信息 → 公司**。

公司资料包括公司名称、简称、公司地址和货运单模板。新增时填写公司名称，必要时填写简称；地址支持录入多个地址，可用逗号或换行分隔；选择该公司的货运单模板后提交。

系统依据客户选择加载对应货运单模板。模板选错会导致送货页面显示的字段与打印格式不符合客户要求。地址包含多个选项时，开单人员需在送货页面选择本次收货地址。

### 4.3 计量单位

路径：**基础信息 → 单位**。

单位资料包含单位名称和单位符号。先维护单位，再在产品资料中选择单位。单位名称应统一，例如“个”“块”“套”；不要为同一含义重复建立不同写法，否则统计结果会分散。

### 4.4 二维码产品

路径：**基础信息 → 二维码产品**。

二维码产品资料包括名称、编码、料号、尺寸和重量。新增时至少填写名称和编码；编码不能重复。后续在“送货二维码”中选择二维码产品并补充版本号、序号等信息。

## 5. 客户供应

路径：**客户管理 → 客户供应**。

供货关系用于定义某个客户可以订购或收取哪些产品，也提供产品物料编码等信息。开送货单时，系统会根据所选客户读取供货产品；按订单模板开单时，系统读取该客户尚未完成的订单。

新增供货关系时选择客户和产品，填写适用的物料编码（如果业务需要），然后提交。若系统提示相同关系已存在，先检查已有关系是否需要编辑，而不是重复新增。

修改或停用供货关系前，确认当前客户是否仍会用它开单。供货关系停用后，相关产品可能不再出现在客户的送货产品选择列表中。

## 6. 订单管理

### 6.1 最新订单

路径：**订单管理 → 最新订单**。

此页面用于查看尚未完成的订单。管理员可新增或编辑订单。一个订单可包含多款产品，每条明细记录产品、型号、数量、版本和备注等信息。

新增订单的基本步骤：

1. 点击“新增”。
2. 输入订单编号并选择客户。
3. 选择该客户对应的产品，录入每款产品的订单数量；按需要填写版本、备注和订单日期。
4. 如订单包含多款产品，点击明细中的“新增”增加产品行。
5. 检查订单编号、客户、产品和数量无误后点击“提交”。

订单编号与客户的组合不应重复。订单明细一旦有送货记录，已送数量不能被调低，已经送过货的产品也不能随意替换。修改订单数量前确认它不小于已送数量。

### 6.2 历史订单

路径：**订单管理 → 历史订单**。

此页面显示已完成订单及产品明细，可查看订单编号、客户、产品、数量、已送数量、待送数量、完成状态和日期。历史订单主要用于查阅，不提供常规编辑入口。

### 6.3 订单送货进度

订单进度由订单数量和累计已送数量决定：

- 待送数量 = 订单数量 − 已送数量。
- 已送数量达到订单数量后，订单明细会标记为完成。
- 订单包含多款产品时，每款产品分别计算进度；所有明细完成后，订单组才算完成。

若订单数量、已送数量或完成状态不符合实际，先检查对应送货单是否已保存、是否关联了正确的订单明细。不要仅凭打印预览判断送货已入账。

## 7. 打印送货单

路径：**送货单 → 打印送货单**。

开单前确认客户、货运模板和本次业务类型。项目当前包含骆驼模板、回天模板、米克模板和签字模板。具体字段会随客户模板改变。

### 7.1 选择客户和产品

1. 在客户列表选择本次收货客户。
2. 系统按客户模板加载可选产品：非订单模板通常从“客户供应”加载；订单模板从客户未完成订单加载。
3. 勾选要送货的产品或订单行，检查产品名称、型号、物料编码和可送数量。
4. 填写送货日期以及模板要求的信息。若客户配置了多个收货地址，必须选择本次地址。

### 7.2 不同模板的主要差异

- **骆驼模板**：通常展示物料编码、产品名称、规格型号、单位、数量、实收数量、生产日期、生产批次和备注。
- **回天模板**：主要展示产品名称、单位、数量和备注。
- **米克模板**：围绕订单编号、产品、单位和数量开单，可关联订单。
- **签字模板**：展示采购订单号、NC 编码、产品名称、规格型号、单位、数量、批次、版本和备注等字段；页面按当前逻辑生成批次日期。

客户资料中的模板决定默认使用哪一种格式。具体字段以实际开单页面为准。

### 7.3 预览、打印和保存

1. 填完明细后点击“打印预览”，核对打印内容和版式。
2. 点击“打印”打开浏览器打印窗口，选择打印机或另存为 PDF。
3. 打印流程完成后，页面会提示是否保存。选择保存才会把送货单写入系统；选择不保存则仅结束打印流程，不生成已保存的业务送货记录。
4. 保存成功后检查成功提示和送货单编号。按订单送货时，保存会更新订单累计已送数量；同时生成库存出库记录并扣减库存。

打印纸张或内容不正确时，先返回修改页面字段并重新预览，不要用旧预览直接保存错误数据。

## 8. 历史送货单

路径：**送货单 → 历史送货单**。

此页面按送货单分组显示已保存记录，可查看客户、产品、数量、地址、日期等信息，并支持重新打印。选择客户可筛选该客户历史记录。

删除历史送货单会影响相关业务：系统会将送货明细和出库记录标记停用；若送货单关联订单，会回退对应订单的已送数量和完成状态；库存数量也会相应恢复。删除前必须确认客户、单号和整单内容，避免误删。

## 9. 库存管理

### 9.1 库存清单

路径：**库存管理 → 库存清单**。

按产品查看当前库存量及累计已送量。管理员可新增、编辑库存记录。新增库存时选择产品并录入现库存量，按页面字段填写累计已送量。产品未维护时，先到“基础信息 → 产品”建立产品资料。

送货单保存后会产生出库记录并扣减库存。不要为了让数字看起来一致而直接修改库存；先核对入库记录、出库记录和送货单。

### 9.2 入库

路径：**库存管理 → 入库**。

登记入库产品、入库数量和入库日期。提交后，系统新增入库记录并增加相应产品库存。编辑或删除入库记录时，系统会同步调整库存。操作前核实入库单据和数量。

### 9.3 出库清单

路径：**库存管理 → 出库清单**。

出库记录通常由保存送货单时自动生成。页面可按产品、客户和日期范围筛选，并可导出 Excel。核对送货明细时，可用送货单号、客户、产品型号和送货日期交叉确认。

## 10. 送货二维码

管理员在“基础信息 → 二维码产品”维护可用二维码产品，然后进入**送货单 → 送货二维码**生成标签。

基本操作：

1. 点击“新增”。
2. 选择二维码产品，录入版本号、序号 1 和序号 2。
3. 点击“保存”，在列表中确认生成记录。
4. 点击“打印”，设置打印份数并确认。

已有记录可编辑、删除或重新打印。打印前核对二维码产品、版本和序号。删除标签资料前确认该标签尚未被业务使用。

## 11. 情义明助手

登录后的业务页面右下角显示“情义明助手”按钮。点击后展开 Dify 聊天窗口；关闭窗口不会退出情义明。

助手当前可回答业务数据查询，例如：

- “订单 CD2026030200203129 目前送货进度如何？”
- “骆驼有哪些产品？”
- “上个月骆驼送得最多的产品是什么？”
- “上个月骆驼送了哪些产品？”

助手会根据问题生成只读 SQL，由 Java 助手接口校验后查询业务库，再根据结果组织中文回答。对于删除、修改等非查询请求，工作流会拒绝处理。助手结果供快速查询参考；订单或库存异常仍应回到相应页面核对原始记录。

助手窗口空白或无法加载时，确认本机 Dify 正在运行、WebApp 地址可打开，且当前浏览器能访问 Dify 所在地址。生产部署时不能继续使用 `127.0.0.1` 作为其他用户访问的地址，应配置可供用户浏览器访问的域名或服务器地址。

## 12. 常见问题

### 找不到某个菜单或新增按钮

确认当前账号角色。基础资料、订单、库存和二维码管理多数仅管理员可见；普通用户的菜单范围较少。

### 客户选择后没有产品

检查“客户供应”是否已为该客户建立有效产品关系；订单模板客户则检查是否存在未完成订单。再确认产品及供货关系未被停用。

### 送货单模板或字段不对

检查“基础信息 → 公司”中的模板配置。该配置决定送货页面加载的模板字段。

### 送货单打印了，但历史记录里找不到

确认打印后选择了“保存”，并看到保存成功提示。仅打印或预览不会自动确保已保存。

### 订单待送数量不对

核对订单数量、关联送货单是否保存、送货单是否关联了正确订单行，以及历史送货单是否被删除或停用。订单和送货汇总异常时联系管理员核对数据库，不要直接改数据库记录。

### 库存数量不对

核对入库记录、保存成功的送货单及出库记录。送货单删除会回退相应库存；不建议通过直接改库存数掩盖流水差异。

### 提交后提示重复

公司按名称、产品按型号、单位按名称、二维码产品按编码、客户供货关系按客户和产品组合检查重复。先搜索已有记录，再决定编辑或继续使用已有资料。

### 页面提示没有权限或跳回登录

重新登录；如果仍无法使用，联系管理员确认账号角色和服务端会话状态。

## 13. 数据与安全注意事项

- 不要将账号密码、注册码、数据库密码、Dify API Key 或助手 API Key 上传到 Dify 知识库。
- 不要把真实客户地址、联系人、订单数据或库存明细作为通用操作手册上传；知识库只放稳定的操作说明和字段定义。
- 重要的新增、修改和删除应依据原始单据操作；删除操作尤其要复核。
- 系统使用软删除标记管理多数业务资料，删除后的记录可能仍保留在历史关联数据中。
- Dify 助手适合自然语言检索和汇总，不代替正式业务操作、单据审批或财务核对。

## 14. 给 Dify 知识库的导入建议

建议将本文件作为“情义明系统操作手册”知识库文档导入，并使用按标题分段的方式。若召回效果不好，可将“基础信息”“订单管理”“打印送货单”“库存管理”“常见问题”拆成独立文档。操作手册回答“怎么操作”；实时订单、送货量和库存应由工作流查询业务数据库，不能只靠这份静态文档回答。

更新系统页面或操作规则后，应同步更新本文档并重新上传或更新知识库文档，避免助手引用旧操作说明。
